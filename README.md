# BKVNengine
BKVNengine is a rust based engine for visual novels made with <a href="https://github.com/iced-rs/iced" target="_self">iced</a> library. It is a school project so please don't expect much <strong>:3</strong><br>

## Launch instruction
Currently there is no official instaler for the application, so in order to use the app you have to pull the code and launch it like a rust project

## List of crates used
